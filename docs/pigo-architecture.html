pigo Architecture

Go 1.27+ command-line AI agent · ACP as the single interactive frontend entry · headless bypass

前端入口

  • pigo.exe（无 -p + TTY）→ TUI/REPL，经进程内 channel ACP
  • pigo.exe -p → headless，直连 runtime.RunHeadless
  • IDE / 外部客户端通过 stdio ACP（JSON-RPC 2.0）
  • stream-json 逐行事件输出给脚本消费

Agent 核心

  • 双层循环：内层 turn，外层 follow-up，统一 finish()
  • 分层系统提示词 + AGENTS.md / PIGO.md
  • 工具执行器 + JSON Schema 参数校验
  • 上下文压缩、持久记忆、checkpoint 挂接

Provider 与协议

  • OpenAI Chat Completions / Responses API
  • Anthropic Messages；OpenRouter 默认路由
  • 内置约 35 个 provider，按模型名启发式匹配
  • SSE 流式传输，retry + 双 watchdog
